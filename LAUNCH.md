## Launch title

**Can My Agent Code This? — an instant agent-readiness score for any GitHub repo**

## Short launch post

Coding agents are improving faster than most repositories are adapting to them.

I made **Can My Agent Code This?**: paste a public GitHub repo and it checks for the boring-but-important stuff agents need — repo instructions, tests, CI, deterministic setup, contribution docs, ownership and security guardrails.

It gives a 0–100 score and tells you the highest-impact fixes.

No login. No API key. No backend. No code from the target repo is executed.

Would love examples of repos it scores unfairly — those are the most useful bug reports.

## Important launch move

Do not post “I made an AI tool, please star it.” Post a screenshot of a recognizable repository's score and ask whether the scoring feels fair. That gives people something to argue with, which is much more clickable.
